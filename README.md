# Financeapp v0.2

Programa de consola hecho en Python para registrar varios ingresos y gastos, asignar categorías a los gastos y calcular el dinero disponible.

## Funciones

- Registra varios ingresos y gastos.
- Valida que las cantidades sean números enteros mayores que cero.
- Permite asignar una categoría a cada gasto.
- Calcula el total de ingresos, el total de gastos y el balance disponible.

## Conceptos de Python practicados

Funciones, parámetros, `return`, listas, `append()`, ciclos `for` y `while`, `input()`, validación con `try/except` y `sum()`.
